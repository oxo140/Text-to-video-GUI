# Origine des projets

Le projet Rust réunit les fonctions des deux dépôts publics de oxo140 :

- GUI : https://github.com/oxo140/Text-to-video-GUI — commit `4eea6c208ab9403eaf20b4b68ff2d25426c28cc9`.
- CMD : https://github.com/oxo140/Text-to-video-CMD — commit `32c09dbd0c634cd5dcfb27058bebab053314e01e`.

Les sources C++ de chaque projet et leurs README sont conservés dans `legacy/gui` et `legacy/cmd`. Les anciennes archives GUI restent dans `legacy/gui`. Les anciens exécutables et DLL du dépôt CMD restent accessibles dans son historique d’origine.

Les historiques Git des deux dépôts sont réunis par un commit de fusion. La nouvelle arborescence Rust constitue l’application maintenue. Le dépôt CMD d’origine n’est ni supprimé ni modifié.
